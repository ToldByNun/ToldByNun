## About

Full-stack engineer building **AI-powered tools, desktop applications, and developer-facing products** — end-to-end, from UI to deployment. Python, TypeScript, Node, and Electron are my daily drivers; LLM orchestration and local-model tooling are where I spend most of my time.

I also have an uncommon background in **low-level systems** — CUDA kernels, Windows drivers, reverse engineering. That work is personal R&D, not my career target: what it gives me is an edge. I know what the machine is doing under my abstractions, so my high-level code tends to be faster, safer, and much easier to debug when things get weird.

Looking for full-stack / AI engineering roles on ambitious product teams.

## Deep Systems & Security Research

<sub>Personal R&D I do to stay close to the metal — this is where my systems intuition comes from. Hobby, not job profile.</sub>

| Project | What it is |
|---|---|
| **kernel-read-driver** | Windows kernel-mode driver for low-level memory operations and `PEPROCESS` CR3 retrieval. |
| **UEFI Bootloader & Kernel Bridge** | Pre-boot execution module exposing controlled Ring -1 memory access interfaces. |
| **Windows UEFI Bootloader Hook** | Proof-of-concept for early-stage system hooking in a controlled environment. |
| **RE-UE4SS_lv-extension** | Live reverse-engineering engine for Unreal Engine apps with integrated disassembler. |
| **Spectre-Memory-Framework** | Zero-dependency C memory library using ASM kernel hooks and `ntdll` redirection. |
| **Chicony Spatial Tracking** | Low-latency positional tracking & prediction algorithm in C++, reconstructed from academic papers. |
